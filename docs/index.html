hummin

A GLM-native terminal coding agent: the pi agent harness (MIT) retuned for Z.ai's GLM models and local inference with colibri and llama.cpp.

GLM is a first-class citizen here, not a compatibility mode. The provider picker surfaces Z.ai and your local servers first, the default model is GLM, and the whole tool assumes you may be talking to a slow, disk-streaming local model instead of a datacenter.

Install

npm install -g hummin-cli

Requires Node >= 22.19. To run from a clone instead: npm install && npm run build, then cd packages/coding-agent && npm link.

Quickstart (Z.ai cloud)

export ZAI_API_KEY=your-key      # or run `hummin auth login zai`
hummin                            # interactive TUI; GLM-5.3 is the default suggestion
hummin -p "summarize this repo"   # oneshot mode

GLM-5.3, GLM-5.3-Flash and GLM-5.3-highspeed ship in the built-in zai provider catalog. Pick models with /model and set a persistent default with the picker's "set as default" action.

Running local models on your own hardware

hummin speaks to any OpenAI-compatible server on your LAN: colibri (huge MoE models streamed off disk), llama.cpp (GGUF), Ollama, anything. One bundled extension turns them all into a single model picker entry with per-server serialization, health probing and real context windows.

The Local models guide is a step-by-step walkthrough: pick an engine, download a model, serve it, and use it in the terminal - with working commands, expected performance, and the gotchas that cost us real time to learn.

What else is in the box

  • Agent teamwork: sessions message each other across terminals and projects, share a task board, spawn bounded subagents, run scheduled wake-ups.
  • Local fleet: one provider across all your OpenAI-compatible servers, health-probed and startable from the model picker.
  • Integrations: MCP client, TypeScript LSP tools, declarative hooks, web search and SSRF-guarded fetch.
  • Safety: bash sandboxing (seatbelt/bubblewrap), destructive-command advisories, loop and budget guardrails, file checkpoints with /rewind.
  • Memory: session distillation into lessons plus a self-curating Obsidian-compatible vault with BM25-ranked recall.
  • Visibility: /context token breakdown, /cost with local-vs-cloud split, /status and /doctor dashboards, two-row statusline.
